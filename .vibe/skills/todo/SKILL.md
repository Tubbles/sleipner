# TODO documents

The project might contain documents which contain work items that needs to be worked on. They might be named TODO.md or similar, and be scattered around in the project in different subdirectories.

When fininshed with any task (not necessarily a previous TODO task) you should look at these documents and grab a work item, and ask the user if you should start working on that. Do not start without a clear, explicit instruction to do so.

When a work item from a TODO document is finished, it can be removed from the document. Bear in mind though that the document itself shall never be deleted even if it is basically empty. This is of course unless the user asks for it to be deleted.

If a work item is big it can be broken down into a list of smaller items directly in the TODO document. As you work through these lists of smaller items they can be removed or marked as completed. When the whole work item is done it can be deleted in its entirety.
